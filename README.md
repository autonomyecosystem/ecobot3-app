# ECOBOT-3 per Android

ECOBOT-3 è l’app del progetto scolastico Robotica Creativa dell’I.C.
“Federico De Roberto” di Catania. Collega il telefono al robot, installa il
firmware via USB OTG e offre i comandi sulla rete Wi-Fi locale del robot.

## Download

Scarica l’APK dalla [release più recente](https://github.com/autonomyecosystem/ecobot3-app/releases/latest).
Il file `ECOBOT-3-1.0.1-release.apk` è firmato e accompagnato da `SHA256SUMS`.
Usa solo i file pubblicati in questo repository.

## Installazione

1. Usa un telefono Android 10 o successivo.
2. Scarica l’APK dalla release ufficiale e verifica il checksum riportato in `SHA256SUMS`.
3. Apri il file dal file manager. Android può chiedere di autorizzare temporaneamente l’installazione per l’app che lo apre.
4. Conferma l’installazione o l’aggiornamento e apri ECOBOT-3.
5. Per il primo firmware prepara un adattatore USB OTG, un cavo dati e una scheda ESP8266 compatibile.

La procedura completa è disponibile su [ecobot3.scuoleaperte.eu](https://ecobot3.scuoleaperte.eu/flash). Le condizioni d’uso e le indicazioni di sicurezza sono nella [pagina dedicata](https://ecobot3.scuoleaperte.eu/condizioni); l’informativa privacy è disponibile su [ecobot3.scuoleaperte.eu/privacy](https://ecobot3.scuoleaperte.eu/privacy).
